# 🍔 UniCuisine - Food Delivery Web App

## 📌 Project Overview

UniCuisine is a full-stack food delivery web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).
It allows users to browse food items, add them to cart, and place orders, while admins can manage the menu and control food items.

---

## 🚀 Features

### 👤 User Features

* User Signup & Login (JWT Authentication)
* Browse food menu
* View food details
* Add to cart
* Place orders
* View order history (My Orders)
* Responsive modern UI

---

### 🛠️ Admin Features

* Admin login system
* Add new food items
* Edit existing food
* Delete food items
* Manage full menu
* Role-based UI (Admin vs User)

---

## 🛒 Order System

* Users can place orders with delivery details
* Orders are stored in MongoDB
* Each order includes:

  * Food name
  * Quantity
  * Price
  * Address
  * Order status (Processing, Delivered)

## ⚙️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/Sagar-hub-sketch/unicuisine-app.git
```

### 2. Install dependencies

```bash
cd backend
npm install

cd ../frontend
npm install
```

### 3. Run the project

Backend:

```bash
cd backend
npm start
```

Frontend:

```bash
cd frontend
npm run dev
```
